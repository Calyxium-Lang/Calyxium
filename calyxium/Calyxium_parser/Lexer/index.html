Module Calyxium_parser.Lexer

exception LexerError of string * Stdlib.Lexing.position

Raised when the lexer encounters an invalid or malformed token.

  • parameter message

    A human-readable description of the error.

  • parameter position

    The lexing position where the error occurred.

val token : Stdlib.Lexing.lexbuf -> Parser.token

token lexbuf reads and returns the next token from the given lexing buffer.

This is the main entry point for the lexer and is responsible for advancing the lexing cursor and producing a value of type Parser.token.

  • parameter lexbuf

    The input lexing buffer.

  • returns

    The next token.

  • raises LexerError

    If an invalid character or malformed token is encountered.

val read_string : Stdlib.Buffer.t -> Stdlib.Lexing.lexbuf -> Parser.token

read_string buf lexbuf processes a string literal starting at the current lexing position. It reads characters until the closing quote and returns the corresponding string literal token.

  • parameter buf

    A buffer used to accumulate string contents.

  • parameter lexbuf

    The source lexing buffer.

  • returns

    A Parser.token representing the parsed string literal.

  • raises LexerError

    If the string is unterminated or contains invalid escapes.

val read_comment : Stdlib.Lexing.lexbuf -> Parser.token

read_comment lexbuf skips or processes a comment starting at the current lexing position. It handles nested or multiline comments depending on the lexer specification.

  • parameter lexbuf

    The source lexing buffer.

  • returns

    The next token following the comment block.

  • raises LexerError

    If the comment is unterminated.
