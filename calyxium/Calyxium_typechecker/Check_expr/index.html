Module Calyxium_typechecker.Check_expr

type type_error =
  1. | Mismatch of Calyxium_parser.Ast.Type.t * Calyxium_parser.Ast.Type.t * string
    (*

    A type mismatch: expected type, actual type, and a descriptive message.

    *)
  2. | UnknownVariable of string
    (*

    The referenced variable is not defined in the current scope.

    *)
  3. | UnknownFunction of string
    (*

    The referenced function is not defined or not in scope.

    *)
  4. | ArityMismatch of string * int * int
    (*

    A function was called with an incorrect number of arguments. Contains the function name, expected arity, and actual arity.

    *)
  5. | UnsupportedStmt of string
    (*

    A statement was encountered that this type checker cannot process.

    *)
  6. | GenericError of string
    (*

    A generic catch-all error with a message.

    *)

The set of type errors that can occur during type checking.

val check_stmt : (string * Calyxium_parser.Ast.Type.t) list -> (string * (int list * Calyxium_parser.Ast.Type.t) list) list -> Calyxium_ir.Ir.instr -> ((string * Calyxium_parser.Ast.Type.t) list * (string * (int list * Calyxium_parser.Ast.Type.t) list) list, type_error) Stdlib.result

check_stmt vars funcs instr type-checks a single IR instruction.

  • parameter vars

    The current variable environment mapping names to types.

  • parameter funcs

    The current function environment mapping function names to overloads (argument arities and return types).

  • parameter instr

    The IR instruction to check.

  • returns

    Either:

    • Ok (vars', funcs') with updated environments, or
    • Error e if a type error occurred.
val check_expr : (string * Calyxium_parser.Ast.Type.t) list -> (string * (int list * Calyxium_parser.Ast.Type.t) list) list -> Calyxium_ir.Ir.expr -> (Calyxium_parser.Ast.Type.t * (string * Calyxium_parser.Ast.Type.t) list, type_error) Stdlib.result

check_expr vars funcs expr type-checks an expression.

  • parameter vars

    The variable environment.

  • parameter funcs

    The function environment.

  • parameter expr

    The expression to check.

  • returns

    Either:

    • Ok (ty, vars') giving the inferred type and an updated variable environment, or
    • Error e if a type error occurred.
val find_return_exprs : (string * Calyxium_parser.Ast.Type.t) list -> (string * (int list * Calyxium_parser.Ast.Type.t) list) list -> Calyxium_ir.Ir.expr -> Calyxium_ir.Ir.expr list

find_return_exprs vars funcs expr collects all return expressions reachable within a function body. This is used to ensure all branches of a function produce a consistent return value.

  • parameter vars

    Variable environment.

  • parameter funcs

    Function environment.

  • parameter expr

    The expression to analyze.

  • returns

    A list of returned expressions found in the body.

val collect_functions : Calyxium_ir.Ir.instr list -> (string * (int list * Calyxium_parser.Ast.Type.t) list) list

collect_functions instrs scans IR instructions for function declarations and builds an environment of function signatures.

  • parameter instrs

    The IR instruction list.

  • returns

    A function environment mapping names to possible overloads.
