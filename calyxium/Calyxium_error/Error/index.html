Module Calyxium_error.Error

Utility functions for error reporting and source extraction.

val get_line : string -> int -> string option

get_line filename n returns line number n from file filename. If the file contains fewer than n lines, returns None.

  • parameter filename

    The path to the file to read.

  • parameter n

    The 1-indexed line number to retrieve.

  • returns

    Some line if the line exists, otherwise None.

val print_error : file:string -> line:int -> col:int -> msg:string -> source:string option -> unit

print_error ~file ~line ~col ~msg ~source prints a formatted compiler-style error message with optional source code context.

  • parameter file

    The filename where the error occurred.

  • parameter line

    The 1-indexed line number of the error.

  • parameter col

    The 1-indexed column number of the error.

  • parameter msg

    The human-readable error message to display.

  • parameter source

    An optional line of source code associated with the error. If provided, a caret (^) is shown at column col.
